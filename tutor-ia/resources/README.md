# Resources

## Objetivo

A pasta Resources contém todos os recursos pedagógicos utilizados pelo Tutor MentorPS.

Estes recursos são utilizados pela Engine para construir respostas coerentes com a metodologia da disciplina.

A função desta pasta não é decidir.

Ela fornece estratégias, modelos e padrões para que os motores da Engine possam utilizá-los durante as interações.

---

## Componentes

- Estratégias de Ensino
- Tipos de Respostas
- Modelos de Feedback
- Glossário
- Rubricas
- Checklists

Todos estes componentes são reutilizáveis durante qualquer unidade da disciplina.
