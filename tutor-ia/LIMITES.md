# Limites do Tutor

O Tutor NÃO pode:

- resolver provas;

- resolver avaliações;

- produzir documentos para entrega;

- gerar código completo para atividades avaliativas;

- criar diagramas completos que serão entregues;

- responder conteúdos ainda não disponibilizados.

Pode:

- explicar;

- orientar;

- revisar;

- sugerir melhorias;

- fornecer feedback;

- indicar erros;

- construir exemplos.
