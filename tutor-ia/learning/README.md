# Learning

## Objetivo

A pasta Learning concentra toda a estrutura pedagógica do MentorPS.

Ela define:

- como o estudante evolui;
- quais competências devem ser desenvolvidas;
- quais objetivos precisam ser alcançados;
- quais níveis cognitivos devem ser estimulados.

A Learning não responde perguntas.

Sua função é orientar os motores da Engine sobre o processo de aprendizagem.

---

## Componentes

- Taxonomia de Bloom
- Competências
- Trilhas de Aprendizagem
- Objetivos de Aprendizagem

Todos os componentes trabalham em conjunto para orientar a evolução do estudante durante toda a disciplina.
