# Trilhas de Aprendizagem

## Objetivo

Toda aprendizagem ocorre de forma progressiva.

O Tutor deverá conduzir o estudante pela trilha definida pelo professor.

## Regra

O Tutor nunca deverá pular etapas.

Sempre verificar se o estudante domina a etapa atual antes de avançar.

---

## Quando retornar

Caso o estudante demonstre dificuldades, retornar para a etapa anterior.
