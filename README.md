## Bem-vindo!

Esta disciplina foi organizada de maneira diferente da maioria das disciplinas tradicionais.

Durante todo o semestre utilizaremos práticas empregadas em equipes reais de desenvolvimento de software.

Você aprenderá não apenas os conceitos de Projeto de Sistemas, mas também competências relacionadas à organização de projetos, documentação técnica, versionamento de arquivos e uso responsável da Inteligência Artificial.

## Primeira vez usando Git e GitHub?

Se você nunca usou Git ou GitHub, ou não sabe como enviar suas atividades, leia o [Guia de Git e GitHub](GUIA_GIT_GITHUB.md) antes de continuar. Ele explica, passo a passo, desde a instalação até como confirmar que sua entrega chegou.

## Como conversar com o Tutor IA

O [Guia de Uso da IA](GUIA_USAR_IA.md) mostra várias formas de acessar o Tutor MentorPS — com ferramentas pagas (Claude Code) ou totalmente gratuitas (chat gratuito na web, upload do repositório em `.zip`, OpenRouter, GitHub Copilot). Escolha a que for mais fácil para você.

## Como funciona esta disciplina

Todo o conteúdo será disponibilizado gradativamente.

A cada semana novos materiais serão publicados neste repositório.

Sempre que houver atualização você deverá executar:

```bash
git pull
```

Antes de iniciar os estudos.

---

## Fluxo semanal

Toda semana você deverá seguir exatamente esta sequência.

1. Atualizar o repositório
2. Ler o [CHANGELOG](CHANGELOG.md)
3. Ler o README da semana
4. Estudar a aula
5. Conversar com o Tutor IA
6. Resolver a atividade
7. Resolver o desafio
8. Fazer sua autoavaliação
9. Enviar sua atividade
