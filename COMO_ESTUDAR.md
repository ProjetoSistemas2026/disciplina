# Como estudar

Esta disciplina foi organizada para que você estude de forma progressiva.

Sempre siga este roteiro.

## Passo 1

Atualize seu repositório.

```bash
git pull
```

## Passo 2

Leia o CHANGELOG.

Veja quais conteúdos foram disponibilizados.

## Passo 3

Leia o README da semana.

## Passo 4

Estude a aula.

## Passo 5

Converse com o Tutor IA.

Faça perguntas.

Peça exemplos.

Resolva dúvidas.

## Passo 6

Resolva os exercícios.

## Passo 7

Resolva o desafio.

## Passo 8

Faça a autoavaliação.

## Passo 9

Envie sua atividade.
