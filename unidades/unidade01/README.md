# Unidade 1 — Introdução ao Projeto de Sistemas

## Objetivo

Nesta unidade o estudante compreenderá os fundamentos da Engenharia de Software e do Projeto de Sistemas.

Ao final desta unidade será capaz de compreender o papel do analista de sistemas, identificar problemas, levantar requisitos iniciais e compreender o ciclo de vida de desenvolvimento de software.

---

## Conteúdos

- Introdução ao Projeto de Sistemas
- Engenharia de Software
- Papel do Analista de Sistemas
- Ciclo de Vida
- Planejamento
- Estudo de Viabilidade
- Introdução aos Requisitos

---

## Competências

Ao concluir esta unidade o estudante deverá ser capaz de:

- compreender o papel do analista;

- compreender o ciclo de vida;

- identificar stakeholders;

- compreender requisitos;

- participar da fase de planejamento.

---
