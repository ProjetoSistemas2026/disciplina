# Aula 01

## Introdução

Bem-vindo à disciplina Projeto de Sistemas.

Durante este semestre trabalharemos utilizando uma metodologia baseada em projetos reais.

Nosso objetivo não será decorar conceitos.

Nosso objetivo será desenvolver competências profissionais.

Durante a disciplina você aprenderá:

- Engenharia de Software
- Projeto de Sistemas
- Planejamento
- Levantamento de Requisitos
- Modelagem
- UML
- Arquitetura
- Desenvolvimento de Projetos

Além disso utilizaremos:

- Git
- GitHub
- Markdown
- Inteligência Artificial

Todo o conteúdo será disponibilizado gradativamente.

A cada semana novos materiais serão publicados.

Antes de iniciar seus estudos execute:

git pull

para atualizar seu repositório.

O GitHub será nosso ambiente oficial de aprendizagem.
